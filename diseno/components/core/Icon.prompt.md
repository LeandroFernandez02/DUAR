Lucide icon wrapper — the product uses lucide-react everywhere; use this for every glyph.
```jsx
<Icon name="map-pin" size={13} />
```
Sizes in the product: 11–13 in header meta and chips, 15–18 in nav, 26–32 for empty states. Requires `<script src="https://unpkg.com/lucide@0.487.0/dist/umd/lucide.min.js">`.
